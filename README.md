# LicenseLoom Intelligent Contract

LicenseLoom is a consensus-backed dependency license receipt. An owner registers a project, manifest URL, lockfile URL on a distinct host, and an allowed SPDX-like set. Validators independently fetch both sources, extract license evidence deterministically, classify COMPLIANT, INCOMPATIBLE, or UNKNOWN, and store both SHA-256 digests.
