# LicenseLoom

LicenseLoom is a GenLayer Intelligent Contract that registers an allowed license policy, refetches a manifest and lockfile from separate hosts, and stores a consensus classification of COMPLIANT, INCOMPATIBLE, or UNKNOWN with package-level reasons and source digests.
